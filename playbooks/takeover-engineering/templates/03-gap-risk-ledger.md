# 模板 03｜缺口与风险台账

> **阶段**：量化 / 划界 ｜ **用途**：把所有「不知道、没实现、有歧义、靠别人」变成可跟踪、可关闭、可追责的条目 ｜ **版本**：v0.1
> **原则**：台账不是会议纪要。**没有关闭条件、责任人和证据的条目，等于没记录。**

---

## 一、条目分类

| 类别 | 定义 | 典型例子 |
|---|---|---|
| **需求缺口** | 需求缺失、矛盾、不可验收 | 文案与界面不一致、异常态未定义、验收标准不可量化 |
| **技术缺口** | 实现缺失、构建失败、契约不明 | 缺文件、依赖不可得、接口未实现、字段口径冲突 |
| **资产缺口** | 源码/环境/账号/设备/文档拿不到 | 无生产只读权限、无样机、无协议文档 |
| **商务/合同缺口** | 范围、责任、付款、授权、退出未定 | 权利归属不清、验收人缺失、变更未计价 |
| **外部依赖** | 依赖第三方或客户动作 | 平台审核、硬件到货、第三方接口开通 |

| 字段 | 必填 | 说明 |
|---|---|---|

| 影响度 | ✅ | 1–5（仅风险项） |

## 三、优先级规则

| 等级 | 判定 | 响应时限 | 关闭要求 |
|---|---|---|---|
| **P0** | 阻断签约/开工/上线；或涉及安全、合规、责任归属 | 2 个工作日内有决策 | 必须有证据 + 书面确认；未关闭不得进入下一阶段 |
| **P1** | 显著影响成本/进度/质量，但有绕过方案 | 5 个工作日内有方案 | 必须有责任人与关闭时间 |
| **P2** | 影响体验或长期维护，不阻断当前阶段 | 进入迭代计划 | 可带入交付，但须在 as-built 中标注 |

### 升级规则

- P1 超过截止时间未关闭 → 自动升为 P0；
- P0 超过 5 个工作日无决策 → 触发止损评审（见模板 05）；
- 同类问题出现 3 次以上 → 升级为系统性问题，需改流程/模板，而不是逐条修。

## 四、风险评分

```
风险分值 = 概率(1–5) × 影响度(1–5)

1–4    低    记录，按 P2 处理
5–9    中    按 P1 处理，需有缓解措施
10–16  高    按 P0/P1 处理，需决策
17–25  极高  触发止损评审
```

**概率口径**：1 几乎不可能；3 有可能；5 几乎必然。
**影响度口径**：1 可忽略；3 影响里程碑或成本 10%–30%；5 影响签约/上线/责任/合规。

## 五、三落点

P0/P1 条目必须同时填写三列：

| 落点 | 填什么 | 不合格示例 |
|---|---|---|
| **合同/商务** | 条款类别（范围/验收/责任/付款/变更/退出） | 「合同里写一下」 |
| **代码** | 约束条件、校验、边界处理、失败行为 | 「代码里注意」 |
| **测试** | 守护测试名、回归用例、失败即阻断 | 「测试一下」 |

**判定**：

- 三列齐全 → 可标记「已闭环（待证据）」；
- 缺任一列 → 状态只能是「处理中」；
- 三列齐全且有证据 → 「已关闭」。

## 七、关闭标准

一条记录只有满足以下全部条件，才能标记「已关闭」：

1. **证据**：有 E1/E2 级证据，或有客户书面确认；
2. **动作**：关闭条件中的动作已完成，不是「已讨论」；
3. **三落点**：P0/P1 的三落点均已落地；
4. **回归**：相关测试已运行且通过（如适用）；
5. **记录**：关闭证据可追溯（链接/测试名/邮件号/签字件）。

**以下情况不算关闭**：

- 「客户说没问题」但无书面记录；
- 「代码已经改了」但无测试；
- 「测试通过了」但测试没覆盖该条件；
- 「下个版本再做」但没有新条目承接。

## 八、评审节奏

| 时点 | 参与人 | 产出 |
|---|---|---|
| 每日/隔日 | 执行者 | 更新状态与阻塞 |
| 每周 | 技术负责人 + 商务 | P0/P1 逐条过，升级/降级 |
| 阶段闸门前 | 决策者 | 未关闭项是否阻断进入下一阶段 |
| 签约前 | 双方 | 待确认项写入合同附件并约定时限 |
| 收尾时 | 双方 | 未关闭项转为「已知问题」并写入 as-built |

## 十、使用提示

1. **台账与报价联动**：每个 E4/E5 条目都应有风险准备金；
2. **台账与合同联动**：P0 待确认项写入合同附件，不写进正文承诺；
3. **台账与测试联动**：能自动化的关闭条件，优先写成测试；
4. **不要用一个台账管所有事**：缺口/风险/变更/缺陷分开编号，避免语义混淆；
5. **定期归档**：关闭项保留，不要删除；它们是复盘和免责的证据。
